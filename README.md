# NEON BASTION

타워로 **미로를 직접 설계**하는 타워 디펜스. 프레임워크와 빌드 도구 없이 JavaScript, Canvas 2D, WebAudio로 실행됩니다.

**▶ [브라우저에서 바로 플레이](https://esin3329.github.io/neon-bastion/)**

## 실행

`index.html`을 브라우저로 열면 바로 실행됩니다. (선택) 로컬 서버로 띄우려면:

```bash
node tools/serve.js
```

## 게임 소개

- 적은 정해진 길이 아니라 **코어까지의 최단 경로**로 움직입니다. 타워를 지으면 길이 막혀 경로가 실시간으로 바뀌므로, 어디에 짓느냐가 곧 맵 디자인입니다. 길을 완전히 막는 배치는 허용되지 않습니다.
- 맵 3종(입구 1·2·4개), 웨이브 30개 + 클리어 후 무한 모드, 10웨이브마다 보스.
- **일일 챌린지**: UTC 날짜로 시드가 정해져 같은 날엔 누구나 같은 웨이브 구성으로 플레이합니다. 오늘의 맵은 날짜로 자동 회전하고, 시드 파라미터 덕에 구성이 매일 달라집니다.
- 타워 8종. 3레벨에서 **두 갈래 특화 중 하나를 골라** 같은 타워도 역할이 갈립니다.
- 조준 방식(선두/최강/근접) 변경, 판매 시 누적 건설·강화 비용의 70% 환급(소수점 버림).

| 타워 | 기본 역할 | 특화 A | 특화 B |
| --- | --- | --- | --- |
| 펄스 | 빠른 연사, 지상·공중 | 개틀링: 초고속 단일 화력, 방어에 약함 | 멀티샷: 세 대상 동시 사격 |
| 모르타르 | 범위 폭발, 지상 전용 | 집속탄: 자탄 4발 재폭발 | 네이팜: 3초간 불길, 방어 무시 |
| 프로스트 | 주변 감속 + 지속 피해 | 절대영도: 범위 내 적이 피해 25% 더 받음 | 빙결: 4초마다 범위 전체 1초 빙결 |
| 테슬라 | 연쇄 번개 | 폭풍: 적 사이 250px 미만이면 최대 10대상 연쇄, 대상마다 피해 10% 감소 | 과부하: 맞은 적의 방어력을 영구히 깎음 |
| 레일건 | 직선 관통, 방어 무시 | 처형자: 체력 20% 미만 즉사 | 가우스: 연사형 |
| 레이저 | 한 대상을 계속 비출수록 피해 증가, 대상이 바뀌면 초기화. 배율이 쌓이기 전엔 탱크에 약함 | 집속광: 3초에 걸쳐 4배, 보스 전담 | 분광: 세 갈래 광선 |
| 증폭기 | 공격 없이 주변 8칸 타워 피해 +, 중첩 안 됨 | 과충전: 피해 +60% | 공명장: 두 칸 거리, 피해 +30%·연사 +20% |
| 미사일 | 유도 범위탄, 공중 피해 2배 | 벌떼: 네 대상 동시 발사 | EMP: 실드 제거, 3초간 재생 차단 |

### 선택을 만드는 장치

- **웨이브 변이**: 8웨이브부터 일부 웨이브에 강철(방어↑)·질주·재생·군단·방벽(실드) 중 하나가 붙습니다. 다음 웨이브의 구성과 변이가 상단에 미리 보여서 웨이브 사이에 대비할 수 있습니다.
- **액티브 스킬**: `Q` 궤도 폭격(지정 위치에 방어 무시 폭발), `E` 시간 정지(전체 3초 정지). 쿨타임은 전투 중에만 줄어듭니다.
- **이자 경제**: 웨이브를 클리어하면 보유 골드의 5%(최대 40)가 붙습니다. 지금 지을지 모아 둘지가 매 웨이브의 판단이 됩니다. 웨이브를 일찍 부르면 남은 대기 시간만큼 보너스도 받습니다.
- **상성**: 실드는 지속 화력이나 EMP, 분열체는 범위 공격, 탱크와 보스는 방어 무시·과부하·레이저로 상대합니다. 플라이어는 미로를 무시하므로 미사일 같은 대공 화력이 따로 필요합니다. 상단 미리보기의 적 표식에 마우스를 올리면 **한 줄 상성 팁**이 뜹니다.
- **배치 퍼즐**: 증폭기는 바로 옆 타워만 강화하므로, 길을 꺾는 자리와 타워를 뭉치는 자리를 함께 고민하게 됩니다.

| 적 | 특징 |
| --- | --- |
| 그런트 / 러너 / 스웜 | 기본 / 고속 / 대규모 무리 |
| 탱크 | 방어력으로 약한 공격을 깎아냄 |
| 플라이어 | 미로를 무시하고 코어로 직선 비행 |
| 힐러 | 주변 아군 회복 |
| 실드 | 체력의 80%만큼 실드, 2.5초간 맞지 않으면 재생 |
| 분열체 | 죽으면 스웜 3마리로 갈라짐 |
| 보스 | 높은 체력과 방어력, 통과 시 내구도 5 감소 |

### 조작

`1`–`8` 타워 선택 · 클릭 배치 · 우클릭/`Esc` 취소 · `U` 강화 · `A`/`B` 3레벨 특화 · `Q`/`E` 스킬 · `X` 판매 · `T` 조준 변경 · `N` 웨이브 호출 · `F` 배속 · `Space` 일시정지 · `M` 소리

## 기술적으로 신경 쓴 부분

- **플로우 필드 경로탐색** — 코어에서 BFS를 한 번 돌려 모든 칸의 남은 거리를 구해 두고, 적은 이웃 칸 중 값이 작은 쪽으로만 이동합니다. 적이 수백 마리여도 경로 계산 비용은 지형이 바뀔 때 한 번뿐입니다. ([js/game.js](js/game.js) `computeField`)
- **배치 검증** — 칸을 임시로 막고 BFS를 다시 돌려, 모든 입구와 이미 필드에 있는 적이 코어에 도달할 수 있을 때만 건설을 허용합니다. (`canBuild`)
- **시뮬레이션과 표현의 분리** — `Game`은 DOM과 Canvas를 전혀 모릅니다. 덕분에 화면 없이 `update()`만 반복 호출하는 봇([tools/balance.js](tools/balance.js))으로 30웨이브 밸런스를 검증합니다.
- **시드 파라미터화** — `genWave(w, seed)`의 seed가 0이면 표준 구성, 그 외면 그 값으로 결정되는 구성이 나옵니다. 일일 챌린지는 UTC 날짜를 시드로 쓰므로 재현·공유가 정확히 가능합니다. ([js/config.js](js/config.js) `dailySeed`)
- **데이터로 맞춘 밸런스**: 같은 예산으로 특화별 타워를 지어 같은 웨이브를 막게 해 보고, 격차가 큰 특화(개틀링, 가우스, 폭풍, EMP 등)를 조정했습니다. 처형자의 즉사 임계는 25%→20%로, 실드 재생 개시는 2초→2.5초로 낮춰 회복 겹침 구간(재생 변이 + 힐러 + 실드)의 벽을 완화했습니다. 맵 난이도 배율은 20웨이브에 걸쳐 서서히 적용해서 초반 학습 구간은 모든 맵이 비슷하고 후반에 차이가 납니다. 미로를 짓지 않는 단순한 봇(`node tools/balance.js mix`) 기준으로 개활지는 30웨이브 승리(내구도 5), 쌍둥이 협곡은 30웨이브 승리(내구도 6), 코어 포위는 20웨이브 패배입니다.
- **자동 밸런스 회귀 검사**: `node tools/balance.js check`가 3맵 도달 성적을 임계값 밴드로 판정해 위반 시 실패합니다. GitHub Actions([.github/workflows/ci.yml](.github/workflows/ci.yml))가 풀 리퀘스트마다 규칙 검증 슈트와 함께 실행합니다. 또 `node tools/compare-branches.js`는 16개 특화를 한 종류씩 단독으로 30웨이브 돌려 격차를 표로 만듭니다(레일건 과점의 원인 분리에 사용).
- **고정 타임스텝** — 1/60초 단위로만 갱신하므로 배속(×1/×2/×4)이나 프레임 저하와 무관하게 결과가 같습니다. 집속탄 자탄의 산개 방향도 시드 고정 난수라 같은 입력이면 결과가 항상 같습니다.
- **데이터 주도 설계** — 타워·적·맵·웨이브 규칙이 모두 [js/config.js](js/config.js)의 데이터입니다. 웨이브는 시드 고정 난수와 예산으로 절차 생성되어 항상 같은 구성이 나옵니다.
- **그래픽과 사운드** — 전장은 Canvas로 그립니다. 스킬 아이콘 2종, 적 표식 4종, 타워 특화 외형 8종, 전장 표식 3종, 회복·시간 정지 효과는 로컬 PNG를 씁니다. 효과음은 오실레이터와 노이즈로 실시간 합성합니다.

```
js/effects.js     파티클·번개·충격파, WebAudio 효과음
js/game.js        시뮬레이션 (경로탐색, 전투, 웨이브, 경제)
js/render.js      Canvas 렌더러
js/main.js        게임 루프, 입력, DOM UI
tools/serve.js    개발용 정적 서버
tools/sim.js      헤드리스 시뮬레이션 공용 봇 (require 모듈)

tools/compare-branches.js  16개 특화 동일 조건 비교 (node tools/compare-branches.js [mapId])
tools/check-effects.js 회복·정지 효과 검증 (node tools/check-effects.js)
tools/check-towers.js  레이저·증폭기·미사일 규칙, 집속탄 결정성, 테슬라 연쇄 거리, 미사일 누적 지출·판매 환급 검증 (node tools/check-towers.js)
.github/workflows/ci.yml  풀 리퀘스트마다 검증 슈트 실행
```
